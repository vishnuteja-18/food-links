# FoodConnect AI — Turning Surplus Food Into Hope 🌿

FoodConnect AI is an AI-powered food donation and surplus food management platform connecting restaurants, hostels, event organizers, and supermarkets with nearby NGOs, orphanages, shelters, and community kitchens in real time.

---

## 🌟 Key Features

- **🍽️ Food Provider Portal**: Easy surplus listing, KPI metric dashboards, real-time demand alerts, and Good Samaritan legal compliance.
- **🤖 AI Freshness & Urgency Matrix**: Auto-calculates perishability, safe shelf-life windows, spoilage risk factors, and priority matching.
- **🏢 NGO Discovery Marketplace**: Real-time map & grid views of nearby surplus donations with live urgency countdowns and 1-click claims.
- **🚚 Live GPS Logistics Tracking**: Real-time delivery fleet telemetry, turn-by-turn route tracking, and secure 4-digit PIN / QR handoff protocol.
- **📜 Verified ESG & CSR Impact Engine**: Live CO₂ emissions diverted, water saved, meals fed, and downloadable/printable CSR tax certificates.
- **🛡️ Multi-Role Architecture**: Seamless persona switching between Food Providers, NGOs/Shelters, Volunteer Couriers, and Platform Administrators.

---

## 🛠️ Technology Stack

- **React 18** (Modern component-based UI)
- **Tailwind CSS** (Custom theme tokens, soft shadows, responsive grids)
- **Lucide Icons** (Clean, minimalist iconography)
- **Canvas Confetti** (Donation celebration effects)
- **Babel Standalone** (In-browser compilation and native execution)
- **LocalStorage Data Engine** (Persistent client-side simulation datastore)

## 🚀 Getting Started Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/vishnuteja-18/food-connect-2.o.git
   cd food-connect-2.o
   ```

2. Start a local server:
   ```bash
   # Using Python 3:
   python -m http.server 3000
   
   # Or using Node.js npx serve:
   npx serve .
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
